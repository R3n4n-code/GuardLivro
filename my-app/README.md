# Biblioteca de Livros - CRUD com React + TypeScript

Projeto de uma aplicação CRUD para gerenciamento de livros, desenvolvido com React, TypeScript e Vite.  
O objetivo foi praticar consumo de API, manipulação de estado e organização de componentes.


## Funcionalidades

- Listar livros
- Adicionar livro
- Remover livro
- Atualização automática da lista


## Recursos usados

- React
- TypeScript
- Vite
- useState
- useEffect
- Consumo de API REST (CRUD)
- CSS / CSS Modules

## Como usar o CRUD-CRUD
A API do CRUD ela expira então o usuario terá que atualizar para testas as funcionalidades da aplicação.

1. Vá para o site do CRUD https://www.crudcrud.com/

2. Copie a URL do endpoint e cole em API em src/componentes/funcoes.tsx
